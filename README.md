# Farmer Crop Adviser

A C++-based Farmer Decision Support System that helps compare crops, estimate potential profits, analyze agricultural risks, and suggest fertilizers based on soil conditions.

## About the Project

The Farmer Crop Adviser is a menu-driven C++ application designed to help farmers explore suitable crop options using basic agricultural information.

The program collects the farmer's name, land size, soil type, rainfall, temperature, and season. Based on predefined conditions, it compares four crops, estimates their potential profits, analyzes agricultural risks, and suggests fertilizers according to soil type.

This project demonstrates the application of Object-Oriented Programming concepts in a real-world agricultural scenario.

## Features

- 👨‍🌾 Farmer details and land size input
- 🌱 Crop comparison and profit estimation
- 🌾 Analysis of four different crops
- 🌦️ Agricultural risk analysis
- 🧪 Soil-based fertilizer suggestions
- 🏆 Best crop recommendation
- 💰 Maximum estimated profit calculation
- 🔄 Menu-driven user interface

##  How It Works

1. The farmer enters their name and land size.
2. The program collects soil type, rainfall, temperature, and season.
3. The crop comparison module estimates profits for Rice, Wheat, Millets, and Pulses using predefined rules.
4. The program identifies the crop with the highest estimated profit.
5. The risk analysis module classifies the risk as Low, Medium, or High.
6. The fertilizer advice module suggests a fertilizer category based on the soil type.

##  How to Run

### Step 1: Compile the Program

Make sure a C++ compiler is installed.

Using GCC or MinGW, run:

```bash
g++ farmer_crop_adviser.cpp -o farmer_crop_adviser
```

### Step 2: Run the Program

**Windows:**

```bash
.\farmer_crop_adviser.exe
```

**Linux/macOS:**

```bash
./farmer_crop_adviser
```

You can also copy the source code into an online C++ compiler to execute it without installing a compiler.
